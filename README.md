# Weather App 🌦️

## Project Overview

This is a Basic Weather App developed using Python. It fetches real-time weather information for a user-specified city or ZIP code using the OpenWeatherMap API.

## Features

- Search weather by city name
- Search weather using ZIP code
- Display temperature in Celsius (°C)
- Display temperature in Fahrenheit (°F)
- Display humidity
- Display weather condition
- Display wind speed
- Handle invalid city errors
- Handle invalid API key errors
- Handle network timeout and connection errors
- Validate empty input

## Technologies Used

- Python
- Requests
- JSON
- OpenWeatherMap API
- python-dotenv
