# Chat Application

A basic client-server chat application built using Python socket programming.

## Features

- Client-server communication
- Multiple clients can connect to the server
- Real-time text message exchange
- Username support
- Join and leave notifications
- Simple command-line interface
- Exit option

## Technologies Used

- Python
- Socket Programming
- Threading

## How to Run

### 1. Start the Server

Open a terminal inside this project folder and run:

```bash
