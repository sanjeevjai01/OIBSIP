# Basic Voice Assistant

## Introduction

This project is a beginner-friendly voice assistant developed using Python. It uses voice recognition to understand user commands and provides responses using text-to-speech.

The assistant can perform basic tasks such as greeting the user, telling the current time and date, opening Google and YouTube, and stopping when the user says a stop command.

## Features

- Voice-based interaction
- Greeting response
- Tells the current time
- Tells the current date
- Tells the current day
- Opens Google
- Opens YouTube
- Handles unknown commands
- Stops when the user says "Bye", "Stop", "Exit", or "Quit"
- Text-to-speech responses

## Technologies Used

- Python
- SpeechRecognition
- PyAudioWPatch
- pyttsx3
- datetime
- webbrowser
